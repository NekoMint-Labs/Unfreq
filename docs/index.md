# Unfreq 文档

Unfreq 是一个 AI 同频匹配的可视化共振社区。

它把匿名表达、AI 扩写、同频匹配和 3D galaxy 放在一条流程里，目标是让用户用一句 seed 进入系统，而不是先学会传统发帖。

## 它怎么工作

```text
seed 输入
  -> AI 扩写
  -> 情绪指纹
  -> 同频匹配
  -> 结果页阅读
  -> resonance
  -> galaxy 可视化
```

如果你想先看系统怎么搭，再看为什么这么搭，先读 [架构与选型说明](./architecture.md)。
