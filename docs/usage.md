# 使用指南

这份文档只讲用户怎么用 Unfreq。

## 一条信号怎么走

```text
首页写 seed
  -> 进入 transmitting
  -> 系统生成 expanded signal
  -> 查看结果页
  -> resonance / 我也想过
  -> 打开 galaxy
  -> 进入 my frequency
```

## 首页

首页只做一件事：接收 seed。

- 用户输入一句话。
- 系统把它当成 seed，不要求标题和长背景。
- 提交后进入 transmitting 状态。

## transmitting

这个页面表示信号已经收到，但还在生成。

- AI 扩写还没结束时，这里会持续展示状态。
- 这样做是为了避免等待时丢失这次发射。
- 刷新页面也能回到同一条信号。

短暂的查询失败会自动重试，成功后错误提示会清除。多次失败后可选择“继续查询状态”；查询恢复不会新建信号。若生成任务明确失败，“重新发射”会创建一条新的信号。

## 结果页

作者可以查看自己的生成结果和私密分析。发布前，先预览将公开的正文、FM 代号和标签，再明确确认发布。其他人只能阅读当前已确认、未撤回的公开版本，不能通过公开页读取作者的原始 seed 或完整分析。

“继续写 seed”会在当前标签页暂存续写内容和父信号，接入 FM 后仍可继续编辑、刷新或提交。新的登录跳转链接不携带 seed 正文；提交成功、选择“清除续写”或关闭标签页后，不再保留这份标签页草稿。浏览器禁止暂存时，续写入口会提示先复制内容。

## galaxy

galaxy 用艺术化星图展示公开表达。

- 你可以拖动和缩放。
- 你可以筛选主频段。
- 你可以点开某个信号继续看细节。

星图会区分“符合筛选”“返回样本”和“绘制”的数量。它最多返回 80 条样本，手机最多绘制 72 个点；样本列表可以阅读同批未绘制的信号。“找到我的信号”定位当前筛选内自己最新公开的一条。公开结果页的“进入星图”和列表中的定位链接会携带这条公开信号，私密、撤回或不符合筛选的内容不会因此进入星图。

打开“星图图例”可以查看各个视觉元素的含义：

- 可点开的星点代表公开表达，背景星尘和远星仅作装饰。
- 位置是艺术化排布，画面远近不表示文字的语义相似程度。
- 连线来自当前样本中的规则关联，还会受显示预算和视觉筛选影响，不代表真实人际关系。
- 颜色区分公开主频段，本人信号另作标记。亮度和大小混合了共振、景深、闪烁等因素，不能用来判断相似度或排名。

点开信号后，“关联说明”会列出同批返回样本中与它有关的规则候选数量。候选记录包含两个方向，按表达去重；这个数字不等于画面连线数，也不是匹配概率。当前样本没有记录时，面板会直接说明，不根据画面距离补出关联。

键盘用户可以打开“查看样本列表”，用 Tab 选择表达，再按 Enter 阅读。阅读层会把焦点留在内部，收藏、共振和举报都可用键盘操作；按 Escape 或关闭按钮后，焦点回到原来的入口。在举报弹窗中按 Escape 只关闭举报，阅读层会保留。

“关闭三维视图”可以停用画布并展开同批样本列表；WebGL 无法接入或上下文丢失时，也会提供列表阅读。列表仍遵守同一份公开数据和 80 条返回预算。系统开启“减少动态效果”后，星图会停止自动旋转和闪烁，取消相机缓动及阅读层的位移动画；拖拽、缩放和列表阅读仍可使用。

## my frequency

my frequency 是自己的表达轨迹。

- 看自己发过什么。
- 看收到多少 resonance。
- 看哪些主题反复出现。

“全部回响”和“历史最高共鸣”来自本人全部已完成且未删除的表达，包含撤回后的私密历史。航行日志每页最多 80 条，可用“较早记录”和“最新记录”翻页；本页数量、频段和想法树不代表全量历史。历史月度回顾仍是生成当时的私密快照，不会因翻页自动重写。

## 举报公开信号

在公开结果页或 galaxy 阅读面板选择“举报”，接入频率后选择原因，按需填写说明并提交。原因和说明仅供后台审核，不向被举报方展示；举报不会自动隐藏信号。同一条待处理举报不会因重复提交而新增，再次打开“举报”可查看和刷新处理状态。

## 常见操作

- 想重新发一条信号：回到首页。
- 想看自己：打开 my frequency。
- 想看整体关系：打开 galaxy。
- 想先弄清楚这是什么：先看 README 或 [文档首页](./index.md)。
