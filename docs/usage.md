# 使用指南

这份文档只讲用户怎么用 Unfreq。

## 一条信号怎么走

```text
首页写 seed
  -> 进入 transmitting
  -> 系统生成 expanded signal
  -> 查看结果页
  -> resonance / 我也想过
  -> 打开 galaxy
  -> 进入 my frequency
```

## 首页

首页只做一件事：接收 seed。

- 用户输入一句话。
- 系统把它当成 seed，不要求标题和长背景。
- 提交后进入 transmitting 状态。

## transmitting

这个页面表示信号已经收到，但还在生成。

- AI 扩写还没结束时，这里会持续展示状态。
- 这样做是为了避免等待时丢失这次发射。
- 刷新页面也能回到同一条信号。

## 结果页

结果页展示：

- expanded signal
- 情绪指纹
- 同频陌生信号
- resonance 入口

这里的重点不是“发布一条帖子”，而是“看见这条 seed 被整理成了什么样子”。

## galaxy

galaxy 是信号关系图。

- 你可以拖动和缩放。
- 你可以筛选主频段。
- 你可以点开某个信号继续看细节。

## my frequency

my frequency 是自己的表达轨迹。

- 看自己发过什么。
- 看收到多少 resonance。
- 看哪些主题反复出现。

## 常见操作

- 想重新发一条信号：回到首页。
- 想看自己：打开 my frequency。
- 想看整体关系：打开 galaxy。
- 想先弄清楚这是什么：先看 README 或 [文档首页](./index.md)。
