`fingerprintJson` 及指纹/频段契约新增可选 `interpretation`：版本 1，状态为 unknown / unverified，来源为 rules / provider / unknown。没有 verified 状态。生成服务在模型结果通过格式验证后，按实际 execution 写入来源并记录审计；模型自填的来源或“已验证”字段不能启用展示。合并 material 与单独 fingerprint 两条路径均覆盖。规则回退、旧数据缺失或非法元数据都按 unknown 处理。

未知结果的作者响应使用中性文案和空标签/关键词，不再把固定需求、冲突或默认“自我怀疑”当作表达结论。PG 枚举值仍为存储兼容保留，不代表可展示或可评分。风险等级保留原有审核规则。Provider 返回仅是未验证的算法参考；`canReferenceSignalInterpretation` 与 `canDisplaySignalInterpretation` 分开，当前没有允许展示心理结论的状态。

新发布预览只含正文、FM 和空标签，省略频段；作者仍须按当前 digest 和版本确认。既有 AUTHOR_CONFIRMED 快照、digest、版本及公开投影不重写；撤回、非作者与异步媒体检查沿用。作者面板不显示心理字段和百分比；本人频段汇总不根据未知/未验证标签归纳心理特征。月度回顾的新输入保留原句、正文和共振数，移除分类/关键词；规则月报回退改用中性摘要，不重写已保存回顾。

匹配遇一方 unknown 或旧来源时，不再因默认频段、情绪、需求相同获得规则分；未知私密查询不带默认心理标签/频段筛选。真实 Provider 的 unverified 分类仍可作为算法输入，其效果尚未校准。向量、reranker、门槛、空结果及公开版本保护保留；已有坐标、向量不改写。共享合成夹具明确标为未验证 Provider 适配器输出；历史确认夹具直接构造历史已确认内容，不能用它证明新预览仍输出心理标签。

新增回归覆盖轻松、喜悦、玩笑、困扰、旧来源、模型自填已验证状态、合并/拆分路径、规则回退与风险保留、空标签发布、旧快照不变、未知匹配不加分和月报输入。Web 专项先有 35/35 临时结果，随后补充标题与元数据约束，不能将该成绩当作最终源码验收：最初 TEMP rename EPERM、缺 workspace 映射导致的收集失败均保留；ESLint 曾因根目录依赖正在重装而未启动。此隔离树没有安装依赖或修改 manifests/lock。

移除未知分类的默认加分可能增加空匹配，尤其是规则回退和旧来源记录。本轮保留既有门槛，没有为维持旧合成分数降低标准；真实匹配效果和门槛仍需另作样本与人评校准。

回退先恢复 API/契约，再回退 Web；不得在仍返回空关键词的新 API 上单独切回旧 Web。保留已有 JSON 元数据、确认快照、向量和坐标，不做数据回写或清理。回退会恢复相应版本的旧推断/展示行为，应在回退记录中明确，而不能把它写成已通过真实效果评测。
