## 最小修复方向与剩余验收

优先复用 PostgreSQL 和 signals 中已有恢复输入，只增加执行元数据；持久领取、租约 / attempt、全局及本地容量、有限安全重试、明确终态、有序关闭与受监督尾工作统一设计。进度、完成和失败都须按有效 token 条件写入；管理员状态变更必须原子失效，防止隐藏后恢复草稿时旧 token 再次有效。

Provider 已外发但结果未知时，不自动重发整个任务；以安全错误收敛，避免把应用超时当作外部未执行或未收费。旧未纳管任务的生产处置、实际迁移和部署切换另行明确，不能假装已完成历史数据恢复。
