# C2 独立提取：举报与私密回执

基于 main `ec54d4c`，来源为归档 #13 的 `f829df1`。复用现有 reports 表、`/api/reports` 与管理员队列，没有新增迁移或举报对象。

作者已确认、当前公开且已完成的信号才可提交举报。事务按 users→signals 锁定并复核，重复待处理举报返回原回执。普通创建响应收窄为回执；原因、说明、举报者身份和后台备注只在管理员接口可读。本人可查询自己的最新回执，目标撤回后仍可查询历史状态。USER 类型的历史举报保留在后台；普通入口不再接受新 USER 举报。

Web 结果页与星图阅读层新增原生举报对话框，支持登录入口、提交、错误提示、回执和状态刷新。说明不进入 URL、浏览器持久存储或日志，不自动隐藏目标。

启用保护时，策略新增 `reportRequestUser`、`reportRequestIp`、`reportReadUser` 三项必填预算。示例中的 0 表示拒绝，不是试运行推荐值；部署时须先确定额度并同步全部 API 实例，旧策略会被严格解析器拒绝。这里没有修改任何目标环境配置。

回退 Web 可保留新 API。若回退 API，应先关闭普通举报入口，再同步旧 API/contracts/策略；旧写入者不具备当前去重及公开性保证。保留既有举报与审核记录，不执行历史清理。

验收覆盖并发去重、跨 PID 配额、当前作者权限、审核队列、撤回、私密响应白名单及浏览器焦点。最终结果记录在本次 PR，旧分支的测试成绩不作为本次结果。
