# 服务端音频播放的独立修复

本候选仅提取旧 #12 的 `9fbb416` 和 `81fe791` 中与播放有关的改动，基于独立 C1 候选 `388bc5c`。它依赖 C1 的版本化音频访问契约，供 C1 独立评审后继续审查；不合并旧维护根分支。

浏览器可能支持 HTML 音频播放而未提供可选的 Speech API。已有 READY 服务端音频在调用 `Audio.play()` 前会因无条件调用 `speechSynthesis.cancel()` 抛错。本修复仅在存在该 API 时取消浏览器朗读，随后仍使用真实 HTMLMediaElement 播放服务端音频。

回归复用 C1 生产 Web 的公开读取与音频权限检查，仅将该用例的 READY 响应和媒体替换为有效静音 PCM WAV。受控浏览器移除 Speech API，检查实际解码、播放、停止、未创建浏览器朗读、未出现页面异常。错误提示断言限定在播放器区域。

本分支继续运行原四项 CI 和完整 C1 生产浏览器套件，不调用真实 TTS，也不据此评价音频质量。精确 Head 的新成绩记在 PR 描述，不复用旧 #12 成绩。未包含环境文件权限、F2 备份、Galaxy/D/E/F 或生产操作。
