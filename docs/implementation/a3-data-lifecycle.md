## 源码复核发现

当前公开详情包含原始输入和较完整分析字段；部分字段存在时还会返回内部身份标识。HIDDEN 的普通详情与本人历史、未完成状态的处理存在差异，已按真实分支记载，未把差异写成线上事故。

系统摘要副本未形成完整来源血缘；AI 审计的目标可空，Provider/model 记录也不等于实际执行血缘。只过滤实时匹配或按一个 signalId 删除，不能证明覆盖所有历史副本。

音频 / OG 与独立上传图片的关联不同；Web fetch 的 no-store 与 HTTP 响应缓存也不同。整库 SQL 备份包含数据库内的 Provider 配置和密文，但不自动覆盖外部配置、主密钥、媒体和 Redis。既有恢复脚本的完成日志不能证明原子成功或公开状态已复核。这些约束分别留给 C1、E1、F2 等实施任务。
